我的判断（按"实际可用性"排序）

  1. E 方向最稳：条不动 → 不碰几何、不影响最小宽度/紧凑态，也没有暂停前后长度跳变的风险。只是表达偏含蓄，需要配合文字。
  2. C3 游标：隐喻清楚（"停在这一格"），实现只是一个三角，成本低。但会超出轨道 2px，需确认与 overflow:hidden 的关系。
  3. D2 胶囊断裂：视觉信息最丰富（已走过 + 冻结 + 余量），但要动 .bar::after，且"余料"的含义可能被误读为"还有进度"。
  4. F 动效：老实说，暂停用动效是矛盾的——动的东西不"停"。F1/F3 的呼吸/脉冲更像"等待中"，可能反而不符合暂停语义。默认建议不做，或只保留 F2 的极慢扫光。
  5. 风险提示：D 方向的分段/余料容易和"已到期（overdue）"的状态混淆，需与 ss-due 的红色体系错开。
实现成本：E 方向与 C1/C2 纯 CSS，零 JSX 改动；C3/C4/D4 用 ::after 即可； D2/D3 需要 .bar::after（也不改 JSX）；只有想精确控制冻结段边界时才需要加空 span。
