6 · 与宿主的一致性 & 已知限制

状态点已与宿主严格同构。实测宿主 StateDot 为「10×10 relative + ::before 10px/inset:0 + ::after 6px/inset:2px」双层同色结构； 本插件按下述同样的写法自绘，未复用宿主的构建期 hash 类名（_dot_xxxxxx_n 不稳定，宿主升级会静默失效）。并排像素比对：scheduled 态与宿主「空闲」行的 span 宽度、中心色 rgb(173,178,184) 逐字段相等。

颜色跟随宿主语义色板，不引入插件专属色。宿主那套点是语义状态色 （done 绿 / ongoing 灰 / warning 琥珀 / error 红）。 早期版本曾用插件专属紫表示「有定时」，问题是它等于在色板里加了第五种含义，且 urgent 时会与宿主 warning 撞色。现映射为： scheduled → ongoing 灰、urgent → warning 琥珀、 overdue → error 红。

⚠️ 已知限制：浅色主题未适配（待办）。上述色值是当前深色主题下从宿主 实测得到的运行时值，宿主自身引用 --dsw-alias-* token、会随主题变化， 而本插件是硬编码常量。因此仅在深色主题下与宿主一致；切到浅色主题或其他配色方案时 本行不会跟随。修法：实测浅色主题下该卡片的实际底色，再改用对应 token。
