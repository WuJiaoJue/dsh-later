# Logo 设计对比

## 当前 Logo（logo.png）

**设计理念**：聊天气泡 + 琥珀色时钟
- 深色背景（#1e293b → #0b1220 渐变）
- 白色聊天气泡，两个点被抠空（typing indicator 效果）
- 第三个点是琥珀色（#fbbf24）时钟，带黑色指针
- 圆角矩形背景（rx=110）

**视觉效果**：现代、简洁，强调"对话中的定时提醒"概念

## 会话状态标识（session-presence badge）

**设计理念**：像素风格时钟
- 10x10 viewBox，shape-rendering="crispEdges"
- 外圈 ring：8个2x2像素块（形成圆形轮廓）
- 指针 hand：2个2x2像素块（竖指针+横指针）
- 紫色（#8b5cf6）为主色调
- 带动画效果：呼吸动画、脉冲动画

**视觉效果**：复古像素风，强调"状态指示"功能

## 像素时钟 Logo 版本（logo-pixel-clock-refined.svg）

**设计理念**：将会话状态标识放大为完整 logo
- 保持像素时钟的核心设计元素
- 放大到 512x512 尺寸
- 添加发光效果（feGaussianBlur）
- 使用紫色渐变（#a78bfa → #7c3aed）
- 中心添加琥珀色圆点（#fbbf24）
- 保留深色背景和圆角矩形

**视觉效果**：复古与现代结合，保持品牌一致性

## 建议

### 可以替换的理由：
1. **品牌一致性**：使用相同的视觉元素强化插件识别度
2. **功能关联**：像素时钟直接关联插件的核心功能（定时提醒）
3. **独特性**：像素风格在 DSH 插件中具有辨识度

### 需要考虑的因素：
1. **尺寸适配**：当前 badge 是 10x10，logo 需要放大到 512x512
2. **可读性**：像素风格在小尺寸下可能不够清晰
3. **品牌策略**：是否与 DSH 整体设计语言保持一致

3. 更新 README.md 中的 logo 引用（如需要）
4. 测试在不同尺寸下的显示效果
