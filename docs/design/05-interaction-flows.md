# 交互流程

---

## 1. 核心流程

### 1.1 创建提醒

```
用户输入消息内容
    │
    ▼
点击 ⏰ 按钮（输入框右侧）
    │
    ▼
面板打开
    │
    ├── 选择"智能时段"
    │   └── 自动计算下一个窗口时间
    │
    └── 选择"自定义时间"
        ├── 选择日期（今天/明天/自定义）
        └── 选择时间
    │
    ▼
预览发送时间和内容
    │
    ▼
点击确认
    │
    ▼
user_schedule_create() 调用
    │
    ├── 成功 → 面板关闭，倒计时开始
    │
    └── 失败 → 显示错误，保留面板
```

### 1.2 到期触发

```
dsh-schedule runMaintenance()
    │
    ▼
发现到期任务（source: 'user-tool'）
    │
    ▼
followup() 注入用户角色消息
    │
    ▼
对话中出现：
[SCHEDULE REMINDER]
Present "提醒内容" to the user...
    │
    ▼
模型看到后转达给用户
```

### 1.3 删除提醒

```
用户点击任务列表中的 [✕]
    │
    ▼
user_schedule_delete({ id })
    │
    ▼
session 日志追加 delete 事件
    │
    ▼
UI 更新，任务从列表移除
```

## 2. 异常流程

### 2.1 时间选择错误

| 错误 | 提示 |
|---|---|
| 过去时间 | "请选择未来的时间" |
| 时间格式无效 | "时间格式应为 HH:MM" |
| 时区未选择 | "请选择时区" |

### 2.2 创建失败

| 错误码 | 提示 |
|---|---|
| `invalid_prompt` | "提醒内容不能为空" |
| `invalid_selector` | "请选择延时、绝对时间或固定间隔之一" |
| `invalid_time_zone` | "请选择有效的时区" |
| `not_future` | "目标时间必须在未来" |
| `frequency_too_high` | "间隔不能少于 5 分钟" |

### 2.3 发送失败

| 场景 | 行为 |
|---|---|
| 网络错误 | 保留任务，下次重试 |
| session 已终止 | 丢弃任务，日志记录 |
| followup 失败 | 保留任务，下次重试 |

## 3. 状态机

### 3.1 任务状态

```
                    ┌──────────────┐
                    │  创建        │
                    │ (create)     │
                    └──────┬───────┘
                           │
                           ▼
                    ┌──────────────┐
            ┌──────│  已调度      │──────┐
            │      │ (scheduled)  │      │
            │      └──────┬───────┘      │
            │             │              │
      删除  │       到期  │         发送  │
            │             ▼              │
            │      ┌──────────────┐      │
            │      │  逾期        │      │
            └─────►│ (overdue)    │◄─────┘
                   └──────┬───────┘
                          │
                     发送 │
                          ▼
                   ┌──────────────┐
                   │  已发送      │
                   │ (delivered)  │
                   └──────────────┘
```

### 3.2 面板状态

```
                    ┌──────────────┐
                    │  关闭        │
                    │ (closed)     │
                    └──────┬───────┘
                           │ 点击 ⏰
                           ▼
                    ┌──────────────┐
            ┌──────│  打开        │──────┐
            │      │ (open)       │      │
            │      └──────┬───────┘      │
            │             │              │
      取消  │       确认  │         关闭  │
            │             ▼              │
            │      ┌──────────────┐      │
            └─────►│  处理中      │◄─────┘
                   │ (processing) │
                   └──────────────┘
```

## 4. 快捷键

| 快捷键 | 行为 |
|---|---|
| `Ctrl+Shift+S` | 打开/关闭面板 |
| `Esc` | 关闭面板 |
| `Enter` | 确认创建（面板打开时） |
| `Backspace` | 删除选中的任务 |
